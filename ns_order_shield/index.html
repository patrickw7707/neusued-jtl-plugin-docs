neusued Order Shield

Das Plugin kann neue Shop-Bestellnummern zufällig wirken lassen und interne Bestell-IDs aus sichtbaren Kundenkonto-Links entfernen.

Version 2.0.0 · JTL-Shop ab 5.3.0

InstallationKonfigurationHinweise

Installation

  1. Das Plugin über die JTL-Pluginverwaltung installieren und aktivieren.
  2. Vor dem Einschalten an einer Testbestellung prüfen, wie Bestellnummern in Shop, Wawi und Kundenkonto erscheinen.
  3. Wenn ein anderes Plugin ebenfalls Bestellnummern verändert, dessen Funktion deaktivieren.

Konfiguration

  1. Unter Plugins → neusued Order Shield „Zufällige Bestellnummern aktivieren“ bewusst auf „Ja“ setzen; die Funktion ist standardmäßig aus.
  2. Die Stellenanzahl (8, 10, 12 oder 14) passend zu Präfix und Suffix wählen.
  3. „Kundenkonto-Verschleierung aktivieren“ ist standardmäßig „Ja“; Links und Formulare im Kundenkonto nach der Aktivierung prüfen.

Hinweise

  • Nur neu im Shop erzeugte Bestellungen erhalten neue Nummern. Vorhandene und aus der Wawi übernommene Nummern bleiben bestehen.
  • Beim Umstieg von einer älteren PluginID ist eine Neuinstallation erforderlich.
